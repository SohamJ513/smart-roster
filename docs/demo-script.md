# Demo video script (target 4 minutes)

Record at 1440x900, browser zoom 100%. Click "Reset demo data" first, and open the app a minute early if it is on a free host (cold start).

| Time | On screen | Say |
|---|---|---|
| 0:00 | Rosters page | "This is a roster tool for an ops manager running 32 people across 25 brands. A solver builds the month, a separate validator checks any roster, and when something changes it shows what broke and how to fix it." |
| 0:20 | Generate December 2026 | "One click generates the month. Zero errors; the warnings are preferences that lost to coverage and days with no spare person." |
| 0:50 | Company view, then Pod view | "Company and pod views. Green is working, grey weekly off, purple leave. The strip under the header flags any day with a problem." |
| 1:20 | Brand view (Lumen Skincare, Orchid Naturals) | "Each brand has its own calendar. Lumen's CS runs every day, ACC Monday to Saturday; Orchid has morning and evening shifts. Numbers are working over required." |
| 1:55 | Process view: Nimbus Home CS | "Each process states its rule: operating days, holiday behaviour, minimum headcount." |
| 2:15 | Add leave: Ritu Agarwal, 25 Dec, Check impact | "Ritu is the only person on PureRoots, which works holidays. Before applying I can preview the impact: zero errors becomes one." |
| 2:45 | Apply, open fix options | "The app ranks fixes: backup cover, swap a day off, or re-plan nearby days. Each is re-validated, so 'Fixes this gap' is verified, not guessed." |
| 3:15 | Apply top backup | "Errors are back to zero." |
| 3:30 | Click a cell, set Leave on a single-resource employee | "Manual edits are checked live, so the new error shows immediately." |
| 3:45 | Publish | "Publishing is gated: unresolved errors must be acknowledged explicitly, and the acknowledgement is stored." |
| 4:00 | README | "Design decisions, assumptions and the answers to your questions are in the README. Thanks." |
